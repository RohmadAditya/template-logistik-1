# template-logistik-1

Templat situs company profile logistik Lookman Djaja Logistics dengan HTML5, CSS3, dan JavaScript murni.

## Menjalankan lokal

```bash
python3 -m http.server 8000
```

Buka `http://localhost:8000`.

## Struktur Halaman

- `index.html` — Beranda
- `profil.html` — Profil perusahaan & sejarah
- `layanan.html` — Layanan kargo, FTL, LTL, dll.
- `armada.html` — Pilihan tipe armada truk
- `tracking.html` — Lacak status pengiriman
- `kontak.html` — Informasi kantor & formulir WhatsApp
- `css/site.css` — Seluruh stylesheet situs
- `js/site.js` — Script navigasi mobile, tracking form, WhatsApp submit form, dan interaksi
- `assets/` — Logo resmi, foto armada, peta wilayah, dan aset grafis

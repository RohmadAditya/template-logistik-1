# Brief — template-logistik-1

## Tujuan
Membuat templat situs company profile logistik yang siap ditinjau, responsif, dan mudah dikembangkan menjadi situs bisnis nyata.

## Asumsi
- Belum ada nama perusahaan, logo, nomor WhatsApp, data armada, foto, testimoni, atau angka operasional yang diberikan.
- Identitas `NusaRoute Logistics`, angka, surel, dan domain pada templat bersifat demonstrasi dan wajib diganti.
- Target utama adalah menghasilkan permintaan penawaran melalui formulir.

## Referensi pola
Referensi: Girteka EU (`https://www.girteka.eu/`).

Yang digunakan hanya sebagai pembelajaran pola: hierarki navigasi, penyajian layanan, angka kepercayaan, jaringan, keberlanjutan, wawasan, dan ajakan penawaran.

Yang tidak digunakan: kode sumber, aset, logo, tulisan, foto, atau identitas visual milik referensi.

## Teknologi
- HTML semantik
- CSS murni dengan token desain
- JavaScript murni tanpa pustaka eksternal
- SVG orisinal untuk ikon dan gambar sosial
